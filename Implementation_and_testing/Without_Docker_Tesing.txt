|| Testing without docker purpose only ||

(NOTE: make sure you already have the ".env" files)

1. Change "config/settings.py"

Find the "DATABASES = {...}"

replace with:

DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.sqlite3",
        "NAME": BASE_DIR / "db.sqlite3",
    }
}

2. Terminal part

Type each one:

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py seed

python manage.py runserver

Then open http://127.0.0.1:8000/ in your browser to test without Docker.
